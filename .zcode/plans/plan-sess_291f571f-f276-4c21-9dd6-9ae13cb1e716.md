## 修改目标

1. 去掉项目卡片底部"重启"按钮前面的图标
2. 重启时若无构建命令，不再弹出"未配置构建命令，跳过构建，直接启动"的提示，静默跳过构建直接启动

## 修改点

### 修改 1：去掉重启按钮图标
**文件：`src/components/project/ActionBar.vue`**

- 删除第 74-76 行的图标模板：
  ```vue
  <template #icon>
    <NIcon><ReloadCircleOutline /></NIcon>
  </template>
  ```
- 从第 13 行 import 中移除不再使用的 `ReloadCircleOutline`（`RefreshOutline`、`CloseCircle` 仍被"构建"按钮使用，保留）：
  ```ts
  // 改前
  import { RefreshOutline, ReloadCircleOutline, CloseCircle } from '@vicons/ionicons5'
  // 改后
  import { RefreshOutline, CloseCircle } from '@vicons/ionicons5'
  ```
- 按钮的 `:title`（hover tooltip「停止 → 启动」/「停止 → 构建 → 启动」）保留，与"静默"诉求不冲突

### 修改 2：重启时无构建命令静默处理
**文件：`src/views/ProjectList.vue`**（`handleRestart` 函数，第 244-253 行）

- 删除 `else` 分支的 `message.info(...)` 提示，改为直接跳过构建：
  ```ts
  // 改前
  if (p.build_cmd?.trim()) {
    const buildOk = await waitBuildDone(p.id)
    if (!buildOk) {
      message.error(`「${p.name}」构建失败，项目已停止，请处理后重试`)
      return false
    }
  } else {
    message.info(`「${p.name}」未配置构建命令，跳过构建，直接启动`)
  }

  // 改后（删除 else 分支，无构建命令时静默进入启动步骤）
  if (p.build_cmd?.trim()) {
    const buildOk = await waitBuildDone(p.id)
    if (!buildOk) {
      message.error(`「${p.name}」构建失败，项目已停止，请处理后重试`)
      return false
    }
  }
  ```
- 注意：只改 `handleRestart`（重启流程）。`handleBuild`（独立"构建"按钮）里第 200-204 行的 `message.warning('该项目未配置构建命令')` 拦截**保持不变**，因为那是显式点击"构建"按钮时的合理反馈，不在本次调整范围

## 影响范围
- 仅前端 2 个文件、3 处改动，无 Rust/DB/IPC 变更
- 不影响构建按钮、启动按钮、停止按钮的行为
