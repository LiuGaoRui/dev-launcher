# 03 - Tauri Command 清单

> 所有 MVP 命令的签名、输入输出、前端调用示例。共 18 个命令。

## 一、命名约定

- 命令名：`snake_case`（Rust 端）→ `camelCase`（JS 端 invoke 时用 snake_case，Tauri 自动转）
- 入参：扁平结构，避免嵌套对象；可选参数用 `Option<T>`
- 出参：`AppResult<T>`，错误统一序列化为 `{ code, message }`

## 二、group 模块

### `list_groups`
- 签名：`fn list_groups(state) -> AppResult<Vec<Group>>`
- 入参：无
- 出参：按 `order` 升序的全部分组

### `create_group`
- 签名：`fn create_group(name: String, state) -> AppResult<Group>`
- 入参：`{ name: string }`
- 出参：新建的 Group（含 id）

### `update_group`
- 签名：`fn update_group(id: i64, name: String, order: i32, state) -> AppResult<Group>>`
- 入参：`{ id, name?, order? }`

### `delete_group`
- 签名：`fn delete_group(id: i64, state) -> AppResult<()>`
- 行为：项目下 group_id 置 NULL（不级联删项目）

## 三、project 模块

### `list_projects`
- 签名：`fn list_projects(group_id: Option<i64>, state) -> AppResult<Vec<Project>>`

### `get_project`
- 签名：`fn get_project(id: i64, state) -> AppResult<Project>`

### `create_project`
- 签名：`fn create_project(input: ProjectInput, state) -> AppResult<Project>`
- ProjectInput：`{ name, group_id?, type, path, start_cmd, build_cmd?, expected_ports, enabled? }`

### `update_project`
- 签名：`fn update_project(id: i64, input: ProjectInput, state) -> AppResult<Project>`

### `delete_project`
- 签名：`fn delete_project(id: i64, state) -> AppResult<()>`
- 行为：运行中拒绝删除（返回 `AlreadyRunning` 错误）

### `pick_directory`
- 签名：`fn pick_directory(app) -> AppResult<Option<String>>`
- 实现：包装 `tauri-plugin-dialog` 的 `open({ directory: true })`
- 出参：用户取消返回 `None`

## 四、process 模块

### `start_project`
- 签名：`fn start_project(id: i64, state) -> AppResult<StartResult>`
- 出参：`{ root_pid: number, log_path: string, started_at: string }`
- 实现：spawn + Job Object + 注册到 ProcessRegistry

### `stop_project`
- 签名：`fn stop_project(id: i64, state) -> AppResult<()>`
- 实现：TerminateJobObject + 从 registry 移除 + 更新 last_stop_time

### `restart_project`
- 签名：`fn restart_project(id: i64, state) -> AppResult<StartResult>`
- 实现：stop → 轮询 Job 活跃数归零（最多 5s）→ start

### `build_project`
- 签名：`fn build_project(id: i64, on_event: Channel<BuildEvent>, state) -> AppResult<BuildResult>`
- BuildEvent：`{ kind: 'stdout'|'stderr'|'exit', data: string|number }`
- BuildResult：`{ exit_code: number, duration_ms: number }`
- 实现：短命令，跑完即退出，stdout/stderr 通过 Channel 实时推送前端

## 五、monitor 模块

### `get_runtime_status`
- 签名：`fn get_runtime_status(project_ids: Vec<i64>, state) -> AppResult<Vec<RuntimeStatus>>`
- RuntimeStatus：`{ project_id, state: 'Stopped'|'Starting'|'Running'|'RunningAbnormal'|'Stopping', pid?, cpu?, memory?, ports: [{port, listening, owner_pid?}] }`
- **批量取**，3s 轮询一次 invoke 拿全量。前端 `stores/monitor.ts` 唯一持有 timer。

## 六、log 模块

### `subscribe_log`
- 签名：`fn subscribe_log(project_id: i64, on_event: Channel<LogChunk>, state) -> AppResult<()>`
- LogChunk：`{ offset: number, text: string }`
- 实现：启动 tokio tail task，轮询读日志文件，新内容通过 Channel 推送
- 退订：前端 Channel 对象 GC → `channel.send` 失败 → task 自动退出（无需显式 unsubscribe）

### `read_log_history`
- 签名：`fn read_log_history(project_id: i64, date: String, offset: u64, limit: u64) -> AppResult<LogHistoryPage>`
- LogHistoryPage：`{ total_size: number, data: string, next_offset: number|null }`

### `list_log_dates`
- 签名：`fn list_log_dates(project_id: i64, state) -> AppResult<Vec<String>>`
- 实现：扫 `{logs_root}/{project_name}/` 目录，返回 `['20260625','20260624',...]`（降序）

### `clear_log`
- 签名：`fn clear_log(project_id: i64, date: Option<String>, state) -> AppResult<()>`
- 行为：`date=None` 清当天；否则清指定日期。truncate 文件（保留文件本身）。

## 七、数据类型 (TypeScript 端)

定义在 `src/types/`，与 Rust serde 自动对齐：

```typescript
// types/project.ts
export interface Group { id: number; name: string; order: number; create_time: string }
export type ProjectType = 'springboot' | 'java_jar' | 'node' | 'docker_compose' | 'custom'
export interface Project {
  id: number; name: string; group_id: number | null;
  type: ProjectType; path: string;
  start_cmd: string; build_cmd: string | null;
  expected_ports: string[];  // JSON.parse 后
  enabled: boolean;
  last_pid: number | null;
  last_start_time: string | null;
  last_stop_time: string | null;
  create_time: string; update_time: string;
}
export interface ProjectInput { /* 不含 id/time，其余同 Project */ }

// types/monitor.ts
export type ProjectState = 'Stopped' | 'Starting' | 'Running' | 'RunningAbnormal' | 'Stopping'
export interface PortStatus { port: string; listening: boolean; owner_pid: number | null }
export interface RuntimeStatus {
  project_id: number;
  state: ProjectState;
  pid: number | null;
  cpu: number | null;       // 百分比
  memory: number | null;    // 字节
  ports: PortStatus[];
}

// types/log.ts
export interface LogChunk { offset: number; text: string }
export interface LogHistoryPage { total_size: number; data: string; next_offset: number | null }
export interface BuildEvent { kind: 'stdout'|'stderr'|'exit'; data: string | number }
```

## 八、错误约定

Tauri 自动把 `AppError` 序列化为 JSON：

```typescript
// 前端捕获
try { await invoke('start_project', { id: 1 }) }
catch (e) {
  // e 形如 { ProjectNotFound: { 0: 1 } } 或字符串
  ElMessage.error(parseError(e))
}
```

前端 `api/invoke.ts` 统一解析错误。
