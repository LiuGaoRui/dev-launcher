## 四、命名约定

- **文件**：`snake_case.rs`（Rust）、`PascalCase.vue`（组件）、`camelCase.ts`（其他 TS）
- **Rust 模块**：`snake_case`，与文件名一致
- **Vue 组件**：`PascalCase`，模板里用 `<PascalCase>`
- **TS 类型**：`PascalCase`，接口不加 `I` 前缀（现代 TS 风格）
- **TS 函数/变量**：`camelCase`

## 五、import 顺序

Rust：`std` → 第三方 → `crate`（用 `use crate::xxx`）。
TS：`vue/第三方` → `@/api/...` → `@/stores/...` → `@/types/...` → `@/utils/...` → 相对路径。

`@` 别名指向 `src/`（在 `vite.config.ts` 与 `tsconfig.json` 中配置）。
