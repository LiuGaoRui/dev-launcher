# 20 - 环境搭建

> 从零搭起开发环境。按顺序执行即可。

## 一、前置依赖

| 依赖 | 版本要求 | 验证命令 |
|---|---|---|
| Node.js | ≥ 20（推荐 22） | `node -v` |
| pnpm | ≥ 9 | `pnpm -v` |
| Rust | ≥ 1.78（stable） | `rustc --version` |
| Cargo | 随 Rust | `cargo -V` |
| Windows SDK | 随 VS Build Tools | 需 `MSVC` 工具链 |

### 1.1 安装 pnpm

```bash
npm install -g pnpm
pnpm -v   # 验证 ≥ 9
```

### 1.2 Rust 工具链

```bash
# 如已装 rustup 可跳过
rustup default stable
rustc --version   # 验证
```

Windows 首次编译 Tauri 需 MSVC 工具链（随 Visual Studio Build Tools 安装「C++ 桌面开发」工作负载）。

## 二、安装项目依赖

在项目根目录：

```bash
pnpm install
```

这会装好前端依赖（vue, element-plus, pinia, vue-router, vite, typescript 等）。
Rust 依赖（tauri, tokio, sysinfo, netstat2 等）在首次 `pnpm tauri dev` 时由 cargo 自动拉取。

## 三、开发模式

```bash
pnpm tauri dev
```

- 首次启动会编译 Rust 后端（约 1-3 分钟），之后增量编译秒级。
- Vite dev server 跑在 `http://localhost:1420`（Tauri 配置）。
- 改前端热更新；改 Rust 会触发后端重编译 + 窗口自动刷新。

## 四、构建发布包

```bash
pnpm tauri build
```

产物在 `src-tauri/target/release/bundle/`：
- Windows：`.msi` 安装包 + `.exe`（NSIS）

## 五、目录快速对照

| 内容 | 路径 |
|---|---|
| 前端源码 | `src/` |
| Rust 后端 | `src-tauri/src/` |
| Tauri 配置 | `src-tauri/tauri.conf.json` |
| 权限声明 | `src-tauri/capabilities/` |
| DB 迁移 SQL | `src-tauri/migrations/` |
| 文档 | `docs/` |

## 六、常见问题

**Q: `pnpm tauri dev` 报找不到 `tauri` 命令？**
A: 确认 `package.json` 有 `"tauri": "tauri"` 脚本，且 `@tauri-apps/cli` 在 devDependencies。

**Q: Rust 编译报 linker 错误？**
A: Windows 缺 MSVC，装 VS Build Tools + 「C++ 桌面开发」。

**Q: 端口 1420 被占用？**
A: `tauri.conf.json` 的 `build.devUrl` 改端口，或关掉占用进程。
